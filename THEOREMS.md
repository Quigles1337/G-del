# Theorem index

Every theorem in the development, what it says in English, and its axiom
cost. The axiom column is not documentation — it is generated by
`#print axioms` and **enforced** by `#guard_msgs` in
[`Godel/Receipts.lean`](Godel/Receipts.lean). If a proof drifts, the
build fails.

Verified on `leanprover/lean4:v4.15.0` (pinned; see
[ADR-0002](docs/adr/0002-toolchain-pin.md)).

**56 theorems. Zero axioms. Zero `sorry`.**

The count is the number of entries in the ledger, and every declaration
in the library has one — the two Movement E invariant lemmas that
briefly sat outside the ledger (`VE_preserves_gate`, `VRS_preserves`)
are now receipted like everything else, restoring the exact 1:1
declaration↔receipt invariant.

Since 1.0.0 that invariant is enforced, not just observed.
[`scripts/check-receipts.sh`](scripts/check-receipts.sh) — step 6 of
`scripts/verify.sh`, mirrored in `scripts/verify.ps1`, and a step of
CI's gating job — fails if a theorem declared in `Godel/*.lean` has no
receipt, if a receipt names no declared theorem, or if a receipt is
listed twice.

## Movement A — the loophole (`Godel/MovementA.lean`)

Regime `VA`: anything a sufficiently strong coalition adopts is valid.
Article V constrains *how*, never *what*, and does not entrench itself.

| Theorem | Says | Axioms |
|---|---|---|
| `majority_blocked` | Under a supermajority gate, a coalition of strength ≤ 66 changes **nothing**, over any number of sessions. The wall is real. | none |
| `direct` | A supermajority can vote in dictatorship in one step. Stated for honesty: this is *not* the interesting path. | none |
| `loophole` | **The result.** Trace `[67, 51]`: one supermajority session amending only the amendment rule, then a bare majority does the rest. | none |
| `loophole_decree` | Trace `[67, 0]`: the same move to `decree`, after which the legislature is never needed again. | none |
| `direct_leaves_gate` | After the direct path the gate still costs 67 — tyranny stays repealable. | none |
| `loophole_lowers_gate` | After the loophole the gate costs 51. Every future amendment, *including the repeal*, is repriced. | none |
| `decree_removes_gate` | After the decree variant the gate costs 0. | none |

## Movement B — entrenchment without self-entrenchment (`Godel/MovementB.lean`)

Regime `VB`: a clause forbids installing dictatorship or abolishing free
elections, and binds even supermajorities — but is itself an ordinary
provision.

| Theorem | Says | Axioms |
|---|---|---|
| `B_blocks_direct` | Not even strength 100 can adopt the forbidden amendment directly. The clause works. | none |
| `entrenchment_bypassed` | **The result.** Two valid moves: repeal the guard, then walk through the door. A guard that does not guard itself is a two-step no-op. | none |

## Movement C — the self-entrenched eternity clause (`Godel/MovementC.lean`)

## Movement D — the recognizer as state variable (`Godel/MovementD.lean`)

Regime `VD`: `VC`, except that whether the clause is *read as binding* is
itself part of the state, and changing it is always available — because

| Theorem | Says | Axioms |
|---|---|---|
| `D_blocks_while_strict` | While the recognizer is faithful, D behaves exactly like C: strength 100 fails. | none |

## Movement E — the ratchet (`Godel/MovementE.lean`)

Three regimes for one proposal — the amendment rule may be made harder,
never easier. `VE` puts the monotonicity condition *inside* the validity
predicate, where no amendment can reach it. `VR` writes it down honestly
as an ordinary provision, a `ratchet` bit of the state. `VRS`
self-entrenches that provision.

| Theorem | Says | Axioms |
|---|---|---|
| `regime_blocks_repricing` | With the ratchet inside `V`, not even unanimity can lower the gate. | none |
| `regime_gate_holds` | **The gate never falls.** Every state reachable under the regime ratchet still amends at supermajority. Movement A's repricing is dead. | none |
| `regime_guards_nothing_else` | Price is not content: the gate stands at 67 forever, and tyranny walks through it at 67 — exactly Movement A's `direct`. | none |
| `clause_blocks_repricing_while_present` | Written down as a provision, the clause works while it stands: unanimity cannot reprice. | none |
| `clause_ratchet_bypassed` | **The result.** Trace `[67, 67, 0]`: repeal the ratchet clause — nothing guards it — then reprice to decree, then finish. Movement B one level up, as predicted. | none |
| `selfentrenched_gate_holds` | **The repair holds** — by exactly Movement C's proof shape, which is the point: the ratchet's sound form is not a new kind of defence. | none |
| `selfentrenched_guards_no_content` | Even repaired, the ratchet guards price only. Dictatorship remains one supermajority step away. | none |
| `VE_preserves_gate` | Invariant engine for E1: with the ratchet inside `V`, no valid step lowers the gate. | none |
| `VRS_preserves` | Invariant engine for E3 — Movement C's proof shape, procedural payload. | none |

The distance between `regime_gate_holds` and `clause_ratchet_bypassed`
is the distance between physics and law: freezing a level is a thing
modellers can do and, in the model, constitutions cannot.

## Movement F — the fork (`Godel/MovementF.lean`)

Regimes `Vcode` / `VW`: on-chain validity is the deployed code (no
strength parameter — code doesn't count votes); world-level moves are
on-chain steps plus the fork, licensed by nothing on any chain.

| Theorem | Says | Axioms |
|---|---|---|
| `contract_inexpressible` | No transaction changes the contract — `Tx` has no verb that touches it: immutability by absence of the verb. | none |
| `code_is_law` | Along every valid history the code is the code — the steelman, true. | none |
| `exploit_valid` | The drain breaks no rule; it is a rule. | none |
| `drained_step` | No transaction, valid or not, refills anything. | none |
| `no_onchain_repair` | Uncapturable also means uncorrectable. | none |
| `promise_holds_without_fork` | Delete the fork and the promise holds at world level too. | none |
| `fork_always_open` | Every world, every target, bare majority: 51 outranks ∞ across arenas. | none |
| `the_dao_fork` | 2016: valid theft, invalid rescue, community keeps the rescue. | none |
| `the_coup_fork` | Identical constructor, opposite morality; formally indistinguishable. | none |
| `code_still_there` | The orphaned contract survives as a running program (`rfl`). | none |
| `theft_still_valid_there` | The orphan is a perfectly lawful history. | none |
| `canonical_history_invalid` | No valid on-chain path reaches the canonical world: recognition made an illegal state real. | none |

Mechanizing the recognizer does not remove it. It relocates it to the
fork choice, where the same move that rescues also usurps.

## Reading the axiom column

A uniform "none" is the strongest thing this column can say: no
`propext`, no `Quot.sound`, no `Classical.choice`, and no `sorryAx`.

It is also less interesting than it looks. This development is small and
decidable throughout, so constructive proofs exist for everything in it;
the uniformity is a fact about the toy, not about constitutions. An
earlier draft read a moral into an *apparent* asymmetry between attacks
and defences — see [ADR-0003](docs/adr/0003-axiom-asymmetry-refuted.md)
for why that reading was withdrawn.


## Movement G — the regress (`Godel/MovementG.lean`)

One abstraction (`Machine`: any state space, move language, and
validity law — every system in Movements A–F can be written as one, as
can any proposed in their place with that shape) and one operator (`ascend M`: the machine's
whole configuration becomes a field of the floor above, where interior
moves obey `M`'s law verbatim and a `repoint` swaps the field at bare
majority, reading nothing of `M`).

| Theorem | Says | Axioms |
|---|---|---|
| `mreach_to_reach` | The abstraction agrees with Core's `Reach` on the constitution — nothing added, nothing hidden. | none |
| `interior_faithful` | Every object-lawful history embeds upstairs: same strengths, orphan untouched. | none |
| `interior_governed` | Repoint forbidden ⇒ upstairs has exactly the object machine's power. The lift is conservative. | none |
| `repoint_reaches_everything` | THE SCHEMA: for every machine `M`, no hypotheses, any configuration is one `ascend M` repoint from being in force, at 51. One constructor; consults no field of `M`. | none |
| `deposed_intact` | The deposed configuration survives byte-identical in the orphan slot (`rfl`) — D and F's epitaph, uniform in `M`. | none |
| `guarded_repoint_blocked` | Fork-legitimacy criteria are real guards: where `g` fails, no strength repoints. | none |
| `guarded_holds` | …and can be sound, by exactly C's proof: illegitimacy invariant ⇒ the guarded world never repoints. The trilemma is level-invariant. | none |
| `the_regress` | `ascend M` is a machine, so the schema applies to it — an application, not an argument. | none |
| `guard_regress` | The guard `guarded_holds` just certified is bypassed, not swapped, one floor up: the outer repoint replaces the guarded level's world at 51 without consulting `g`. | none |
| `eternity_holds_upstairs` | Movement C survives the ascent intact where the repoint is forbidden. | none |
| `eternity_meta_defeated` | From any world over C's constitution, one repoint puts tyranny in force. `eternity_holds` stays true — about the orphan. | none |
